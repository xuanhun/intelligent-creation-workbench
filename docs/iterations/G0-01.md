# G0-01：模型与 Runtime 可行性验证

状态 planned，依赖 B00。固定真实 SDK/Runtime/网关/模型组合，验证最关键假设。

## 所需输入

模型名、Responses 端点、凭证注入方式、能力目录、隔离目录与预算尚未确定。不得猜测端点、借用当前 Codex 登录态或把密钥写入仓库。

## 工作包

1. 核对官方 SDK API、平台支持、匹配 Runtime 与许可证，固定安装锁。
2. 实现 RuntimeAdapter 生命周期、并发写入限制、事件映射与错误分类。
3. 真实模型跑通“读取资料 → 分析工具 → 创建文章版本 → 修改选中段落 → 恢复会话”。
4. 接入可取消的异步媒体模拟 Job，验证等待、重复通知、取消后禁止提交与单次唤醒。
5. 保存真实响应与失败，更新兼容能力表和下一轮 brief。

## 验收

SSE 完整结束、工具 call_id 正确关联、结果后继续生成、跨 Turn 恢复；断流、超时、限流、无效配置与取消可区分。模拟 Job 与真实模型分别报告。未通过不宣称 G0 完成。
