# 基础服务与部署边界

B00 的核心检查与 API/Web 本机运行，不依赖容器。当前无生产部署配置，不启动数据库或付费服务。

| 服务 | 用途 | 阶段 |
| --- | --- | --- |
| PostgreSQL | 租户、业务状态、产物索引、outbox、幂等 | G1 / G0 按需 |
| Redis | 缓存与通知，不保存唯一任务记录 | G1 |
| S3 | 素材、规范源、预览和导出 | G1 |
| Temporal | 等待、重试、恢复与取消 | G0 原型 / G1 |
| Codex Worker | 隔离身份、工作目录、租约与进程 | G0 |
| Render / Publisher | 固定字体/镜像、渠道授权与对账 | G2 / G3 |

接入时提交固定镜像、开发 compose、迁移、健康检查、持久卷和恢复说明。模型推理、媒体渲染与业务服务分资源池。示例凭证留空，通过环境或凭证服务注入。
